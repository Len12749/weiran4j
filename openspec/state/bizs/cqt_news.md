# cqt_news 大赛动态（常青藤）

> 属于 `openspec/state/`，只记录当前实现事实；业务表索引见 [`README.biz.md`](README.biz.md)。

## 0. 概要

| 项 | 值 |
|---|---|
| 表 | `cqt_news` |
| 菜单 / 页面 | 后台「站点资料 → 大赛动态」`/cqt/news`；uniapp 首页与「大赛动态」页 |
| 接口 | 后台 `/api-backend/cqt/news`；公开 `/api-web/n/product/news`、`/api-web/n/product/newsdetail` |
| 排序 | `sort`、`id` 升序 |

## 1. 列表

后台分页查询，可按标题关键字过滤。前台动态页查询全部动态；首页只查询 `show_on_home=1` 的动态。

## 2. 字段与表单

| 字段 | 列 | 说明 |
|---|---|---|
| 标题 | `title` | 必填，最多 255 字符 |
| 首图 | `image` | URL，可空；后台支持 jpg/jpeg/png/gif 图片上传，最大 10 MB |
| 是否首页展示 | `show_on_home` | boolean；首页接口仅返回 true 的记录 |
| 排序 | `sort` | 非负整数，值小优先 |
| 内容 | `content` | 必填 HTML 原文，富文本编辑 |

## 3. 动作

新增通过隐藏路由 `/cqt/news/create`（菜单 1015）打开后台页签，保存或取消关闭当前页签返回列表；保存自动刷新列表查询。新增权限按钮 1012 挂在隐藏菜单 1015 下，后续角色授权可自动保留祖先路由。编辑通过隐藏路由 `/cqt/news/edit/:id`（菜单 1016）打开独立页签，不同记录分别打开；按钮 1013 归属菜单 1016。新增和编辑共用 `NewsForm`，成功保存关闭当前页签并刷新、返回列表。

后台增删改查分别需要 `cqt:news:create/update/delete/list`；上传图片需要新增或编辑权限。写操作记操作日志。公开接口无需登录。

## 4. 用到的公共组件

首图使用系统配置同款 `FileUpload`：支持点击/拖放上传、预览、移除，限制 jpg/jpeg/png/gif 和 10 MB。后台富文本编辑器复用 `SiteConfigRichEditor`。
