# cqt_school_import_tasks / cqt_school_import_rows 学校批量导入

## 0. 概要

weiran-cqt 学校作品导入。任务归属于前台学校账号，任务 ID 为不透明字符串；请求中的 userid 不决定归属。使用已有任务和源行表，作品写入沿用报名领域规则。

## 1. 列表

我的页面按赛事查询本学校历史任务。任务显示上传、排队、处理中、完成、部分成功、失败状态及真实行数；点击记录恢复轮询或查看结果。其他学校及不存在的任务统一返回不存在，学生无权读取。

## 2. 字段与表单

任务包含账号、学校、赛事、Excel/ZIP 地址和名称、状态、总行数、处理行数、成功/失败数、租约、重试次数和时间。任务级 error_message（varchar(2000)，追加迁移 V202610170200）保存无源行时的解析错误等原因，并通过 message 显示。源行保存行号、原始数据、PENDING/SUCCESS/FAILED 状态、作品 ID 与错误原因。团体各成员仍按真实源行计数。

前台先上传文件、登记会话，再确认提交；上传和登记全部成功才显示完成。confirm 返回 task_id 与同值兼容别名 job_id。不显示模拟上传百分比或不存在的附件匹配统计。

## 3. 动作

- 模板下载、ZIP/Excel 登记、确认入队、后台异步处理；上传会话两小时过期。
- importProgress/{taskId} 查询轻量汇总，importResult/{taskId} 查询逐行结果；原 getTaskResult/getTaskDetail 保留兼容。
- 处理行数由已成功/失败源行实时汇总；非终态百分比最高99，终态100。空模板显示“报名表没有可导入的作品行”，失败终态为0行且100%，不伪造源行。PENDING 不归入失败。
- 前台一次请求完成后再安排下一次查询；隐藏、卸载、换任务时停止并忽略旧响应，返回页面恢复。网络错误可手动重试，终态停止并展示结果。

## 4. 用到的公共组件

uniapp 我的页面现有上传和弹层；请求与轮询逻辑复用 util/school-import.js。

## 5. 说明与建议

省赛、国赛奖项不进入本次导入；成功作品后续按评审流程处理。成功/失败/已处理数表示源行数量，团体人数会影响计数，不能解释为作品件数。

## 6. 已知问题汇总

- **#01 🚧 P2 长任务租约缺少续租与执行隔离**：现有处理租约固定15分钟，无执行代次校验；多实例或单任务耗时超过租约时，另一执行器可能接管，旧执行器仍可能继续回写状态。作品指纹可防重复创建，但不能保证两个执行器的任务状态回写顺序；部署多实例前需补续租与 fencing。
