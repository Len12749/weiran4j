# Proposal

## Why

系统配置需要成为各模块共用的可配置底座，同时支持按字段元数据渲染与校验。现有字典主表与配置分组统一为 `sys_group`，以类型区分并复用；配置页面采用字典管理式的主从布局。站点配置当前没有通用价值，应移除。

## What Changes

- 将配置分组持久化到可复用的 `sys_group(type=config)`，配置字段元数据继续驱动动态表单与服务端校验。
- 系统配置页面采用左侧分组导航、右侧内容面板。
- 支持从配置分组侧栏刷新分组并新增配置分组；新增配置项默认使用当前选中分组。
- 配置分组侧栏展示创建时间和内置标识；删除权限与可删除条件由条目操作菜单体现，右侧标题只显示分组名称。
- 将 `sys_dict` 主表迁移为通用 `sys_group`；`type` 支持 `config` 与 `dict`，原字典记录与配置组按类型隔离。
- 系统配置页面改为左侧分组导航、右侧配置内容。
- 统一配置键使用 `system.` 前缀，并将现有 `sys.` 配置迁移。
- 删除站点配置页面、接口、菜单、领域与存储实现及 `sys_site_config` 表。
- 图片库保留为独立的系统能力。

## Capabilities

| 能力 | delta 操作 | 说明 |
|---|---|---|
| `admin-foundation` | MODIFIED | 系统配置改用 `sys_group` 的 config 类型分组、双栏管理、表单元数据、统一键前缀与站点配置移除约束。 |
| `system-media-library` | REMOVED + ADDED | 移除依赖站点配置的图片删除要求，新增独立图片资产删除要求。 |

|---|---|---|---|---|

## 共享层影响(决定能否并行)

| 类别 | 是否命中 | 说明 |
|---|---|---|
| `weiran-dependencies` BOM | ☐ | 不新增依赖。 |

| 前端路由与菜单 | ☑ | 移除站点配置菜单与页面，系统配置页面改为动态表单。 |

## Dependencies

- 产品/设计：左侧配置组导航，右侧由配置项元数据决定控件。
- 后端：新增通用分组模型及配置分组校验，追加 Flyway 迁移。
- 前端：配置表单双栏改造，站点配置页面移除。
- 数据库变更：`sys_dict` 改为 `sys_group`、写入配置分组、配置字段、重命名配置键、删除 `sys_site_config` 表与菜单；保留 `sys_dict_item`，将 `dict_id` 改为 `group_id` 并保留关联值。
- 测试：编译和构建校验；测试用例随已有配置测试同步。
