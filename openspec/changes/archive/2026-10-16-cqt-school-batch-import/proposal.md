# Proposal

## Why

- 背景：uniapp 已有学校 Excel/ZIP 批量导入页面，但其后端接口尚未在 CQT 服务实现。
- 业务目标：学校账号能从现有报名模板批量建立作品及成员记录，并查看导入进度和逐行结果。
- 当前问题：页面上传后无法完成登记、导入、任务查询；旧页面的结果弹窗还把学校列显示成联系方式。
- 需求来源：见 `interview.md` 与提供的报名示例工作簿。

## What Changes

- 新增：学校导入会话、持久化任务与逐行结果；模板下载、学校作品查询、确认导入及任务查询接口。
- 改造：CQT 报名领域支持按表头解析个人/团体记录并按作品组校验；uniapp 修正行数据显示。
- 复用：现有 CQT portal 认证/响应、赛事/赛项与组别配置、作品成员和参赛唯一键、文件上传存储。
- 下线/不做：省赛/国赛奖项列在本次导入中完全忽略；不实现无调用方的旧进度轮询代码。

## Scope

### In Scope

- 按示例模板表头解析个人和团体作品；团体以连续 N 行组成一组，赛项、专业、作品名及人数必须一致。
- 建立可恢复的异步导入任务与逐行结果，校验学校账号、赛事、作品和附件，沿用报名唯一键约束。
- 对齐 uniapp 当前实际调用的学校模板、待处理检查、作品列表、上传登记、确认导入、任务列表和详情接口。
- 只导入作品和参赛成员，不读取、不校验、不写入省赛/国赛评价结果。

### Out of Scope

- 不实现学生个人报名表单、报名修改/撤回、评审/奖项/成绩/证书、后台赛事与作品管理。
- 不读取或校验导入模板中的省赛奖项、国赛奖项列；赛事阶段评价在作品导入之后处理。
- 不新增后台管理菜单或后台批量导入页面。
- 不改上游文件；只在 `AGENTS.biz.md` 许可的 CQT、uniapp、业务脚本和 OpenSpec 下游范围内实现。

| 能力 | delta 操作 | 说明 |

| `cqt-entry-signup` | ADDED | 扩展作品报名能力，增加学校批量创建作品、成员及查看导入结果的行为 |

## 横切关注点

| 项 | 是否涉及 | 说明 |
|---|---|---|
| CC-1 权限点 (`pam_permission`) | ☑ | CQT portal 不使用后台 RBAC；所有任务接口要求登录且校验学校账号类型 |
| CC-2 菜单(前端硬编码,无后端表) | ☐ | 不新增后台管理菜单 |
| CC-3 数据范围 (`data-scope`,尚未引入) | ☑ | 不引入通用数据范围；任务、上传会话和作品列表必须按当前学校账号/学校归属过滤 |
| CC-4 多租户隔离 (`tenant`,不适用) | ☐ | 本系统不是多租户系统 |
| CC-5 审计日志(登录日志 + `@OperationLog` 操作日志) | ☑ | portal 写操作按 CQT 业务审计约定记录任务事件；不把证件号、电话、令牌和原始行内容写入日志 |
| CC-6 字段脱敏 (`masking`,尚未引入) | ☑ | 任务详情仅学校本人可查；响应提供导入所需原始行/错误信息时限制字段和访问范围，日志不输出个人信息 |
| CC-7 幂等 (`idempotency`,尚未引入) | ☑ | 上传登记/确认重试和任务恢复不得重复创建作品，依赖持久化任务状态、逐行状态及作品导入指纹 |
| CC-8 导出 / 任务中心(尚未引入) | ☑ | 新增 CQT 专用持久化导入任务与详情，不扩展通用任务中心 |
| CC-9 工作流绑定(不适用,系统内暂无审批引擎) | ☐ | 导入不触发审批工作流 |

## Dependencies

- 产品/设计：用户提供的 Excel 模板及已确认的团体分组和奖项边界。
- 后端：现有 CQT portal、赛事/赛项配置、报名写入、FileStorage。
- 前端：uniapp 现有 `/api/**` 页面调用经 `main.js` 改写为 `/api-web/**`。
- 数据库变更：在 CQT migration 目录追加任务与任务行表；不修改既有迁移。
- 运维/配置：沿用现有存储配置；导入文件只读取本服务管理的对象，不抓取任意外链。
- 测试：CQT domain/application 测试、weiran-app portal 集成测试、uniapp pnpm 构建。

## Risks

| 风险 | 触发场景 | 应对方案 |
|---|---|---|
| ZIP 炸弹或路径穿越 | 恶意或异常压缩包 | 限制条目数、单文件/总展开大小，并拒绝越界路径 |
| 任务重试产生重复作品 | 进程重启或客户端重复确认 | 任务与行状态持久化、作品导入指纹唯一约束、事务内提交每个作品组 |
| Excel 隐私数据泄露 | 任务详情或异常日志暴露证件/电话 | 学校所有权过滤，日志不输出原始行；接口只返回页面需要的字段 |
