# E6：站点配置与图片库前端

## 完成的 tasks.md 条目

- 5.1

## 改了什么

新增 system 站点配置编辑器与图片库页面，支持多图粘贴/选择、逐项上传、搜索、分页、预览、复制和引用保护删除；移除旧管理页面和客户端类型。

## 为什么这么做

- 关键决策：批量上传顺序执行，编辑器上传时锁定编辑区，保证插入顺序和光标位置。
- 放弃方案：无并发上限的 Promise.all 会同时请求大量文件，插入位置也可能因编辑发生变化。

## 依赖的契约

- `exec/plan.md` §4 接口路由与 DTO；页面组件路径由迁移菜单登记。
