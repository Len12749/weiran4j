## ADDED Requirements

### Requirement: [FR-008] 行政区划专属错误码

行政区划能力 **MUST** 为父级或层级无效、区划代码重复、节点仍有子级三个稳定错误场景分别返回六位数字码 `120101`、`120102`、`120103`，并保持各场景原有 HTTP 状态。

#### Scenario: 区划错误按地区服务号返回
- **WHEN** 分别触发无效层级、重复区划代码和删除仍有子级的节点
- **THEN** 错误响应的 `code` 分别为 `120101`、`120102`、`120103`
- **判据**:接口测试断言三种响应的数字 `$.code` 及对应 HTTP 状态。
