# Proposal

## Why

现行五位码把 HTTP 状态和错误类别耦合，模块间无法按服务、资源、错误三个层级管理。用户要求改为六位，通用、系统、地区服务号分别为 `10`、`11`、`12`。

## What Changes

- 将当前错误定义、接口返回、前端按码分支和现行规格同步为六位数字。
- 为三个服务登记号段，保留 HTTP 状态独立定义和成功码数字 `0`。
- 复用 `ErrorCode`、现有错误枚举、统一响应及前端 `ApiError`。

## Scope

### In Scope

- 框架通用、系统认证、地区专属错误；调用方、测试、现行规格和契约文档。

### Out of Scope

- 不改历史归档 change 与决策记录中的当时错误码。
- 不改变成功响应的数字 `code=0`，不改变失败响应的字段形状。
- 不改变登录、权限、区划等业务判断和对应的 HTTP 状态。

## Capabilities

| 能力 | delta 操作 | 说明 |
|---|---|---|
| `admin-foundation` | MODIFIED | 后台底座错误响应及认证、权限场景 |
| `external-identity` | MODIFIED | 外部身份登录错误场景 |
| `user-list-search` | MODIFIED | 用户列表参数错误场景 |
| `administrative-regions` | ADDED | 地区专属错误码号段 |

## 影响的包

| ID | 包 | 动作 | 影响说明 | Owner |
|---|---|---|---|---|
| PK-1 | `weiran-framework` | 改造 | 通用错误枚举与统一错误响应的码值 | 框架 |
| PK-2 | `weiran-system-*` | 改造 | 认证专属错误与业务调用处 | 系统 |
| PK-3 | `weiran-app` | 改造 | 集成断言与跨模块码值约束 | 应用 |
| PK-4 | `web` | 改造 | 会话失效、SSO 与页面错误分支 | 前端 |

## 共享层影响(决定能否并行)

| 类别 | 是否命中 | 说明 |
|---|---|---|
| 构建配置与 BOM | ☐ | 不改构建依赖 |
| `weiran-framework` 错误码契约 | ☑ | `CommonErrors` 是跨模块码值来源，先冻结映射 |
| `weiran-app/build.gradle.kts` | ☐ | 不改依赖聚合 |
| 前端路由与菜单 | ☐ | 不新增页面或菜单 |

## 横切关注点

| 项 | 是否涉及 | 说明 |
|---|---|---|
| CC-1 权限点 | ☐ | 权限判定和权限码不变 |
| CC-2 菜单 | ☐ | 不增删菜单 |
| CC-3 数据范围 | ☐ | 不改变查询范围 |
| CC-4 多租户隔离 | ☐ | 未引入租户机制 |
| CC-5 审计日志 | ☑ | 操作日志保存新的响应码，字段类型仍为 int |
| CC-6 字段脱敏 | ☐ | 不改变日志敏感字段 |
| CC-7 幂等 | ☐ | 不改变写操作语义 |
| CC-8 导出 / 任务中心 | ☐ | 不改变导出和任务 |
| CC-9 工作流绑定 | ☐ | 没有审批引擎 |

## Dependencies

- 后端与前端须同步发布，以免旧前端把新码误判为普通错误。
- 不需表结构、配置或定时任务变更；只更新测试与现行规格。

## Risks

| 风险 | 触发场景 | 应对方案 |
|---|---|---|
| 会话不清理 | 前端仍识别旧未登录码 | 同步常量和响应断言 |
| 规格漂移 | 主规格仍断言五位码 | 通过 delta spec 归档更新 |
