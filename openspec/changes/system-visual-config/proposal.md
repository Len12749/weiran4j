# Proposal

## Why

系统配置需要成为各模块共用的可配置底座，同时支持按字段元数据渲染与校验。分组编码保持内置，暂不允许管理页面扩充分组；未来可在此模型上继续发展低代码配置。站点配置当前没有通用价值，应移除。

## What Changes

- 新增固定分组目录与配置字段元数据，支持按 Tab 管理、动态表单渲染和服务端校验。
- 统一配置键使用 `system.` 前缀，并将现有 `sys.` 配置迁移。
- 删除站点配置页面、接口、菜单、领域与存储实现及 `sys_site_config` 表。
- 图片库保留为独立的系统能力。

## Capabilities

| 能力 | delta 操作 | 说明 |
|---|---|---|
| `admin-foundation` | MODIFIED | 系统配置增加内置分组目录、表单元数据、统一键前缀与站点配置移除约束。 |
| `system-media-library` | MODIFIED | 图片资产删除解除对已移除站点配置的引用检查。 |

## 影响的包

| ID | 包 | 动作 | 影响说明 | Owner |
|---|---|---|---|---|
| PK-1 | `weiran-framework` | 不涉及 | 复用现有响应、错误与权限契约。 | — |
| PK-2 | `weiran-system-*` | 改造 | 配置领域/API/持久化、站点配置模块删除、媒体库删除逻辑解耦。 | system |
| PK-3 | `weiran-app` | 不涉及 | 沿用 system 模块自动装配。 | — |
| PK-4 | `web` | 改造 | 系统配置动态表单，移除站点配置页面。 | web |

## 共享层影响(决定能否并行)

| 类别 | 是否命中 | 说明 |
|---|---|---|
| `weiran-dependencies` BOM | ☐ | 不新增依赖。 |
| `weiran-system-api` 跨模块契约 | ☑ | 配置视图、写入命令与分组接口增加字段。 |
| `weiran-framework` 错误码/分页契约 | ☐ | 沿用现有契约。 |
| `weiran-app/build.gradle.kts` 依赖聚合 | ☐ | 模块结构不变。 |
| 前端路由与菜单 | ☑ | 移除站点配置菜单与页面，系统配置页面改为动态表单。 |

## 横切关注点

| 项 | 是否涉及 | 说明 |
|---|---|---|
| CC-1 权限点 (`sys_menu.permission`) | ☑ | 清理站点配置权限，保留系统配置权限。 |
| CC-2 菜单 (`sys_menu`) | ☑ | 追加迁移删除站点配置菜单。 |
| CC-3 数据范围 (`data-scope`) | ☐ | 不涉及数据范围。 |
| CC-4 多租户隔离 (`tenant`) | ☐ | 本项目不采用多租户。 |
| CC-5 审计日志 (`audit-context`) | ☑ | 配置写操作继续记录操作日志。 |
| CC-6 字段脱敏 (`masking`) | ☐ | 不引入敏感配置字段。 |
| CC-7 幂等 (`idempotency`) | ☐ | 不涉及重试型写操作。 |
| CC-8 导出 / 任务中心 | ☐ | 不涉及。 |
| CC-9 工作流绑定 | ☐ | 不涉及。 |

## Dependencies

- 产品/设计：按内置分组显示 Tab，由配置项元数据决定控件。
- 后端：配置领域/API/持久化扩展，追加 Flyway 清理迁移。
- 前端：配置表单改造，站点配置页面移除。
- 数据库变更：新增字段、重命名配置键、删除 `sys_site_config` 表与菜单。
- 测试：编译和构建校验；测试用例随已有配置测试同步。
