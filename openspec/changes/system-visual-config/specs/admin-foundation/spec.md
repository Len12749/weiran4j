## ADDED Requirements

### Requirement: [FR-013] 分组式系统配置表单

系统配置 **MUST** 以代码定义的内置分组目录按 Tab 展示，管理页面 **MUST NOT** 提供新增分组编码的能力；不同模块的配置项 **MAY** 共用这些分组。每个配置项的表单字段类型、选项与必填规则 **MUST** 决定控件渲染和前后端校验。支持单行输入、多行文本、数字、布尔开关、下拉选择和 JSON 字段，值类型必须与字段类型兼容。新增和修改配置 **MUST** 使用 `system.` 键前缀；内置配置 **MUST** 保留键名且不可删除。匿名配置读取 **MUST** 只允许 `system.site.*`，且不隐式改变前端展示。系统站点内容配置及其存储表 **MUST NOT** 存在。

#### Scenario: 内置分组生成 Tab 与动态表单
- **WHEN** 管理员打开系统配置页面
- **THEN** 代码定义的每个分组显示为 Tab，Tab 内按配置元数据渲染字段控件和必填/选项校验
- **判据**:分组接口只返回内置目录；前端表单使用对应控件，提交前与服务端拒绝无效值

#### Scenario: 配置项使用共享分组
- **WHEN** 管理员新增带 `system.` 键前缀的配置项并选择一个内置分组
- **THEN** 配置项被保存并显示在该分组表单中
- **判据**:重新查询后字段元数据完整保留，分组 Tab 可见

#### Scenario: 用户分组提供手机号验证码登录开关
- **WHEN** 数据库迁移创建内置系统配置
- **THEN** `system.user.enable_phone_login` 以 `user` 分组的布尔开关呈现，初始值为 `false`
- **判据**:系统配置接口返回该内置配置，用户 Tab 显示关闭状态

#### Scenario: 移除站点内容配置
- **WHEN** 管理员使用当前版本数据库迁移
- **THEN** 站点内容配置菜单与 `sys_site_config` 表被移除
- **判据**:菜单不再返回站点配置，数据库不存在该表
